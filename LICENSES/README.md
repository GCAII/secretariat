# License texts

> **Status:** Active · **Version:** 1.0.0 · **Date:** 2026-11-08

**This directory contains only this README.** It exists for the canonical texts of licences that are not yet in use.

The licence that actually applies today is **CC BY 4.0**, and its full canonical text is the root [`LICENSE`](../LICENSE) file. That is the file GitHub reads.

Files to add here when, and only when, they are needed:

| File | Added when |
|---|---|
| `Apache-2.0.txt` | the first code, harness, or script is committed |
| `CC0-1.0.txt` | the vectors and schemas move to CC0 |

There is no `CC-BY-4.0.txt` here because the root `LICENSE` already is that text. Duplicating it in two places invites drift.

## Why split at all

- Specifications need to be reusable and citable: CC BY 4.0.
- Code needs a patent grant: Apache-2.0.
- Test vectors should be usable without attribution friction: CC0 1.0.

The intended split is recorded in [`LICENSING.md`](../LICENSING.md).

Do not edit a canonical text. If a licence changes, add a new file and update `LICENSE`.
