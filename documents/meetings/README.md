# Meetings

> **Status:** Active · **Version:** 1.0.0 · **Date:** 2026-11-08

Public notes from maintainer or community meetings, if any are held.

## Format

`YYYY-MM-DD-<topic>.md` with:

- attendees (names or handles, with consent);
- agenda;
- decisions and links to ADRs;
- action items with owners;
- next meeting.

## Rule

If a decision is made in a meeting, it is not final until it is recorded as an ADR or RFC outcome. Meetings do not create authority.
