# Licensing

> **Status:** Active · **Version:** 1.0.0 · **Date:** 2026-11-08

The root [`LICENSE`](LICENSE) file contains the canonical **CC BY 4.0** text and is what GitHub detects. It applies to everything currently in this repository: documentation, specifications, policies, programs, and governance records.

This page records the intended split once executable code exists.

| Material | Planned licence | Canonical text |
|---|---|---|
| Documentation, specifications, policies, programs, governance (`*.md`) | CC BY 4.0 | <https://creativecommons.org/licenses/by/4.0/legalcode> |
| Code, harnesses, scripts, CI workflows | Apache License 2.0 | <https://www.apache.org/licenses/LICENSE-2.0> |
| Test vectors, JSON schemas, metadata | CC0 1.0 | <https://creativecommons.org/publicdomain/zero/1.0/legalcode> |

## What this means

At 1.0.0, only the first row applies. When the split takes effect:

- **CC BY 4.0:** you may share and adapt these documents, including commercially, with attribution.
- **Apache-2.0:** you may use, modify, and distribute code, including commercially, with a patent grant and attribution.
- **CC0 1.0:** test vectors and schemas are dedicated to the public domain; no attribution required.

## Status

At 1.0.0, everything in this repository — including the JSON Schema and test vectors — is licensed under CC BY 4.0. No Apache-2.0 or CC0 material exists yet.

When the first executable code lands, this section is updated, `LICENSES/Apache-2.0.txt` is added, and the test vectors and schemas move to CC0 with a per-directory `LICENSE` file.
