# Decision Records

> **Status:** Active · **Version:** 1.0.0 · **Date:** 2026-11-08

Architecture and governance decisions are recorded as ADRs. An ADR is dated, immutable, and superseded rather than edited.

## Format

Each ADR contains:

- **Context** — the situation and constraints.
- **Decision** — what was decided.
- **Consequences** — what follows, including tradeoffs.
- **Status** — proposed, accepted, superseded, or rejected.
- **Links** — RFCs, issues, releases.

## Naming

`ADR-NNNN-short-title.md`, numbered sequentially. Never reuse a number.
